状态：**草案，待审。未锁契约、未跑。** 需先确认第 7 节的 3 个参数。

## 1. 定位

前两阶段证明：常态满仓的短中频择时打不穿摩擦（15m 毛/成本 0.04、1h 2x 即崩），
结构性收益也在衰减（carry 12%→2.7%、截面离散度 21.8%→7.3%）。

Phase 3 不再赌方向。它要回答的是：

> 用同一批免费数据，**只做仓位管理**（波动率目标 + 风险平价），
> 能不能在显著压低回撤的同时，把夏普和卡玛比做到比 Buy & Hold 更好？

这是一个**风险管理问题**，不是 alpha 问题。跑赢了不等于找到 alpha，
只等于"用更少的波动拿到了相近或更好的收益"。

## 3. 基线 1：BTC 单币波动率目标

```
每个交易日 D（UTC 00:00 决策，D 开盘成交）：

  σ20 = stdev(过去 20 个日收益率) × sqrt(365)        # 年化实现波动
  w_target = min(目标波动 / σ20, 1.0)                 # 不加杠杆，上限 100%
  if |w_target - w_now| > 10%:                        # 缓冲带
      w_now = w_target                                # 否则不动
```

- 预热：前 20 个交易日不出信号
- 成本：11bps/边（现货 taker 10 + 滑点 1）
- 不做空、不加杠杆、不做止损

## 4. 基线 2：三币倒数波动率风险平价 + 同口径波动率目标

```
  σ_i  = 各币 20 日年化实现波动
  raw_i = 1 / σ_i
  base_i = raw_i / Σ raw_j                            # 风险平价权重，Σ = 1
  σ_p = 组合按 base 权重的 20 日年化实现波动
  k = min(目标波动 / σ_p, 1.0)
  w_i = k × base_i
```

- 缓冲带：组合总敞口 `Σw_i` 变动 > 10% 时整体再平衡；否则不动
- 成本、成交时点同基线 1
- 不做币种择时、不做动量叠加

## 6. 评估

### 6.1 切分

- 全样本：2023-11-27 → 2026-11-24（3.0 年）
- 样本外：2025-11-25 → 2026-11-24（最后 1 年，与 Phase 2 同口径）

### 6.2 指标

年化收益、年化波动、夏普（日频 × √365）、最大回撤、卡玛比（年化收益 / MDD）、
年换手次数、成本拖累（bps/年）。

### 6.3 判定门槛（事前写死）

| 编号 | 门槛 |
|---|---|
| Q1 | 全样本夏普 > BTC B&H 夏普 |
| Q2 | 全样本最大回撤 ≤ BTC B&H 回撤 × 0.70（压缩 30%+） |
| Q3 | 全样本卡玛比 > BTC B&H 卡玛比 |
| Q4 | 样本外夏普 ≥ BTC B&H，且 MDD ≤ B&H × 0.70 |
| Q5 | 2x 成本（22bps/边）下 Q1-Q4 仍成立 |
| Q6 | 年均调仓 ≤ 10 次（保证"成本可忽略"不是空话） |

- 全部满足 → NOT_FALSIFIED
- 任一不满足 → FALSIFIED

按用户原话："显著优于"量化为 Q1-Q4；Q6 是我加的防呆，避免用高频交易换回撤。

## 8. 已知风险与反方观点（必须先说清）

1. **这是牛市样本**。2023-11 → 2026-11 包含一轮大牛市，波动率目标会在波动抬升时减仓，
   大概率**跑输 B&H 的绝对收益**。如果用户期待"更高收益"，这个方案会失望。
   它唯一可能赢的是**风险调整后**指标（夏普、卡玛）和回撤。
2. **Q2 的 30% 回撤压缩可能不成立**。BTC 在该窗口的实际最大回撤需实测；
   要压缩到 70% 需要波动率目标非常灵敏，而灵敏就意味着 whipsaw 和更高换手，与 Q6 冲突。
3. **20 日窗口对跳空反应慢**。2024-08-05、2025-10-11 这类单日暴跌，实现波动率要到
   一周后才反映，期间仓位仍是满的。
4. **波动率目标不是 alpha**。它改变的是收益分布形状，不改变期望。长期看，
   波动率目标策略的收益通常低于满仓，只是回撤更小。若用户要的是"更高收益"，方向就错了。
5. **3 年样本只覆盖一个完整周期的一半**。结论外推到下一个周期需要谨慎。
