## 3. 规则草案

```
每 7 天调仓（UTC 周一 00:00 决策，D 开盘成交）：

  disp = stdev(候选池 12 币的过去 14 日收益) × 100        # 截面离散度 %
  if disp < 阈值:
      全部平仓，FLAT（持有现金，收益按 0 计）
  else:
      按 funding 年化排序
      做空 funding 最高的 3 个（收资金费 + 赌拥挤反转）
      做多 funding 最低的 3 个（避免付费）
      等权，gross = 1，net = 0
```

- 成本：往返 24bps，`Σ|Δw| × 12bps`
- FLAT 期间不产生交易成本，也不产生 funding
- 资金费逐 8h 真实结算
