# 时间序列动量（TSMOM）研究：一次以证伪为目标的检验

**结论先说：在 2020-09 至 2026-11 的 10 个加密资产日线上，没有找到能通过严
格检验的时间序列动量 alpha。先前一版结果里 82.3% 的「通过选择性检验」是
对照组构造缺陷造成的假象，修正后降到 6.2%，而这个 6.2% 本身也无法与多重
比较产生的随机噪声区分。**

这不是一个失败的实验。它是一个有效的证伪结果——它排除了一整类假设，并且
过程中的两处测量缺陷本身比结论更值得记录。

---

## 1. 要检验的假设

上一轮讨论提出的路线是：先测三个传统基线，再用消融实验判断 AI 能带来什么。
本报告完成前一半。

| 编号 | 基线 | 定义 | 参数 |
|---|---|---|---|
| A | 传统动量 | 过去 N 日累计收益的符号决定多空 | N ∈ {10,20,30,60,90} |
| B | 风险调整动量 | 过去 N 日日均收益的 t 值超阈值才持仓 | N 同上，阈值 ∈ {1.0, 2.0} |
| C | 动态动量 | 动量给方向，200 日均线给许可（多头需在均线上方） | N 同上，均线 200 |
| D | 纯多头腿 | A 的多头部分单独成策略 | 用于检验「钱是 alpha 还是 beta」 |
| E | 纯空头腿 | A 的空头部分单独成策略 | 同上 |

标的：BTC / ETH / BNB / SOL / XRP / ADA / DOGE / LINK / LTC / BCH（10 个）
样本：2020-09-01 → 2026-11-26，日线，**所有币截到同一窗口**（否则「年化」
不可比）。EOSUSDT 因数据止于 2025-05-26 被剔除。

**数据集本身**：15 币日线，零空洞，最早 2017-08-17。资金费 7,907 条
（2019-09-10 起），来自币安公开端点，全程只读。

## 2. 方法：信号与测量彻底分离

这是整个设计的地基。

```
signals.py   只把「过去 N 天涨没涨」翻译成持仓方向，不计算任何损益
run.py       只调度引擎、搬运数字
verify.py    策略证伪引擎，独立推演每一笔的成交、成本、退出
```

写信号的人不算收益，算收益的人不知道信号怎么来的。如果这两件事由同一段
代码完成，审计就退化成自己给自己判卷。

### 时点语义（错一根 K 线就是前视偏差）

- 信号在 bar i **收盘**可知 → 引擎在 bar i+1 **开盘**成交
- 一次翻仓 = 旧仓在 i 收盘平 + 新仓在 i+1 开盘建
- 中间隔的跳空是真实成本，且系统性不利于策略（宁可低估毛收益）

`position[i]` 的计算里没有任何下标大于 i 的项——结构上不可能前视。

### 事前证伪规则（写进 spec，先于任何数字存在）

```json
"falsify_if": {
  "worst_case_net_negative": true,        // 最坏口径不赚钱
  "net_negative_at_fee_multiple": 2,      // 双倍成本就亏
  "control_lift_ci_includes_zero": true,  // 与随机入场无显著差异
  "grid_positive_ratio_min": 0.5,         // 退出参数一半以上为正
  "min_fills": 30
}
```

跑之前写死，跑完不改。这是唯一有效的做法——看完成绩再定标准，任何策略都
能被「做」成正期望。

## 3. 两处必须记录的测量缺陷

### 缺陷一：混合多空让两条基线同时失效

初版用多空混合的策略（例：BTC 30 日，138 空 / 137 多）。引擎的两条基线都
只镜像**主方向**：

- 随机对照组变成「在涨了 14 倍的 BTC 上随机做空」，必然巨亏 →
  「选择性 proven」是白送的
- 买入持有基准变成「做空 BTC 九年」，得出 **−1321%** 这种荒谬数字

**修正**：多空拆成两条腿分别测。拆开后立刻暴露了被混合统计掩盖的真相——
long 腿差 −2.16pp（CI 跨 0，无选择性），short 腿差 +8.09pp。混在一起时这两
个反向信号互相抵消，看起来像个中庸的「还行」。

### 缺陷二：对照组被持有到世界末日（这一处最严重）

spec 里 `timeout_bars=100000` 相当于「永不超时」。策略靠退出信号逐段平仓，
**平均持仓 14.7 根、中位 3 根**。但随机对照组没有退出信号，只吃同一个超时
——每个随机入场都被持有到数据结束，**最长 2277 根（约 6 年）**。

在涨十几倍的币上，随机做空六年单笔亏损能到 **−334%**，而真实账户早爆仓了，
引擎不建模强平。

由此产生一个可诊断的特征：

```
SOLUSDT 对照组：均值 −9.93%/笔   最差 −334.7%
                中位 +1.48%      胜率 54.3%
```

中位数和胜率都是正的，只有均值被极值拖死。这不是「随机入场很差」的证据，
这是「对照组持有期与策略差 50–150 倍」的证据。

**修正**：对照组超时对齐到策略持仓段长度的中位数。

**修正前后（策略自身的数字一个都没变，只有对照组变公平）：**

| | 通过选择性检验 |
|---|---|
| 修正前 | 247 / 300 = **82.3%** |
| 修正后 | 3 / 48 = **6.2%** |

跌了 13 倍。那 76 个百分点全是构造出来的。

## 4. 修正后的结果

### 4.1 三个存活者，逐个核实

| 策略 | 算术净 | 复利 | 笔数 | CI | 裁决 | 样本外 |
|---|---|---|---|---|---|---|
| BTC 空头 20 日 | +38.2% | 1.33x | 124 | [0.01, 2.05] | **FALSIFIED** | −19.94% |
| BTC 空头 60 日 | +82.3% | 2.07x | 51 | [0.35, 4.09] | INCONCLUSIVE | +18.30% |
| ETH 空头 60 日 | +61.4% | 1.69x | 47 | [0.33, 4.27] | INCONCLUSIVE | +18.65% |

第一个 CI 下界仅 **0.01pp**（几乎贴着 0），样本外 −19.94%，五倍成本转负
−1.52%，裁决直接 FALSIFIED。三个独立信号一致指向噪声。

后两个判 INCONCLUSIVE 是因为样本不足（47–51 笔），样本外只有 15–20 笔。

### 4.2 多重比较：3 个显著 vs 期望 2.4 个

我在 48 个配置里搜，出现 3 个 p<0.05：

```
检验次数 n = 48
名义显著  k = 3
纯随机期望   = 2.4          ← 关键
Bonferroni 阈值 = 0.05/48 = 0.001
```

**3 与 2.4 无法区分。** 三者反推的 t 值：1.90 / 2.21 / 2.25，全部落在多比较
下的噪声区间。Bonferroni 阈值是 p<0.001，现有结果约为 p≈0.03，差两个数量级。

在 48 个配置里找到 3 个 p≈0.03 的结果，不是发现，是噪声的上界。

### 4.3 多头的钱从哪来

| 变体 | n | 亏（复利<1） | 赚 | 中位复利 | 中位在场 |
|---|---|---|---|---|---|
| tsmom（多空） | 50 | 23 | 27 | 1.61x | — |
| **tsmom_long** | 50 | 12 | **38** | **4.64x** | 36.0% |
| **tsmom_short** | 50 | **42** | 8 | **0.34x** | 39.1% |
| riskadj | 100 | 42 | 58 | 1.37x | — |
| regime | 50 | 30 | 20 | 0.60x | — |

多头腿 38/50 赚钱、中位 4.64 倍；空头腿 42/50 亏钱、中位 0.34 倍。

**这是「上涨市场里做多赚钱、做空亏钱」，不是择时能力。** 与公平对照组只有
6.2% 通过率完全吻合：钱来自方向暴露（beta），不来自入场时点。

### 4.4 beta 剥离：估计本身极不稳定

定义 `beta_null_pct = 窗口内标的涨幅 × 在场比例`，即「同等多头暴露但完全不
择时」的毛收益，再与策略的算术净收益相减。两者都不复利，同口径可比。

| 口径 | 结果 |
|---|---|
| 中位数超出 | **+125.5 pp** |
| 均值超出 | **−946.1 pp** |
| 为正的 | 35 / 50 |
| 范围 | −12,953 ~ +4,617 pp |

中位数 +125pp 看起来像「择时确实有贡献」，但**均值是 −946pp，范围跨了四个
数量级**。原因是分布被单币极值主导：

```
DOGE 90 日   算术 +5095%   beta 零假设 478%   超出 +4617pp
SOL  60 日   算术 +1581%   beta 零假设 1018%  超出  +563pp
LINK 90 日   算术   −42%   beta 零假设  625%  超出  −668pp
```

DOGE 一个样本就贡献了 +4617pp。把这个估计量交给任何一个审稿人，得到的回答
都是一样的：**均值不可用，中位数也不足以支撑「存在 alpha」的主张**。

所以这一节能得出的唯一结论是：**beta 剥离的估计量本身不稳定，不足以区分
「择时贡献」与「个别币的极端行情」。** 它不能支持 alpha 存在，也不能完全
排除——它是一个被噪声淹没的测量，不是一个否证。

（这一节否定的是「多头腿赚的钱可以归因于择时」这一主张，而不是反过来主张
「择时一定无效」。后者需要分布形状对齐的对照组，见第 6 节第 2 条。）

## 5. 成本：资金费才是主角

初版只算了手续费（往返 8bps）。实测资金费后才看清量级：

| 项目 | BTC 九年累计 |
|---|---|
| 手续费（往返 8bps × 275 笔） | 约 22pp |
| **资金费（均值 +1.041bps/8h）** | **+82.32%** |

资金费均值 1.041bps/8h × 1095 次/年 ≈ **年化 11.4%**，是多头长期持仓的真实
成本，比手续费高一个数量级。9 个币里 8 个正费率占比 80% 以上——多头在绝大多数时段付费。

（BTC 多头腿实测：接入资金费后算术净收益从 455.91% 降到 431.97%，成本
23.94pp。这比按在场比例推算的全额低，因为引擎按实际持仓时长比例扣，口径
正确。）

**这一点直接改变了策略设计的方向**：任何「长期持多」的动量策略，先要跨过
年化 11.4% 的资金费门槛。空头反而收资金费——但空头在上涨市场里方向就错了。

## 6. 这个研究没有回答的问题

诚实列出边界，不给空泛的「未来展望」：

1. **波动率目标（position sizing）测不了**。引擎每笔等权，无法表达「仓位
   大小 = 目标波动 / 已实现波动」。而波动率缩放恰恰是 TSMOM 文献里最核心
   的改进（Moskowitz-Ooi-Pedersen 与 volatility scaling 两篇都强调这点）。
   本报告测的只是方向层面，不是完整的 TSMOM。
2. **对照组分布形状没对齐**。中位持仓对齐只对齐了中心，策略是「动量翻转」
   退出、对照组是「均匀入场 + 固定超时」，尾部不同。
3. **组件的联合检验缺失**。10 个币各自独立测，没有测「等权组合」——截面
   分散本可以降低波动、提高夏普。这是 TSMOM 文献的重点，本次未做。
4. **样本期只有一次**。2020-09 起是加密资产的大牛市，空头结论高度依赖这段
   历史。样本外折数 4 折，每折约 1.5 年，不足以覆盖多个市场周期。
5. **AI 消融完全没开始**。用户提的第三步（AI 能否带来额外收益）需要先有一
   个能站住的基线。基线现在证明了不存在，消融实验失去参照。

---

## 7. 结论

**在测过的 300 个配置里，没有一个能在公平对照组、双倍成本、样本外一致性
三个检验下同时存活。**

更有价值的产出是两处测量缺陷：

- 「混合多空 → 基线失效」是可复现的陷阱，任何用这类引擎测双向策略的人
  都会踩到；
- 「对照组无限期持有 → 82.3% 的假阳性」是本次最重的发现。策略数字一个没
  变、只把对照组改公平，结论就从「有 alpha」翻成「没 alpha」。

如果只报修正前的数字，这个研究会得出与事实相反的结论。
