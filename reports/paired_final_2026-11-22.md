## 结论先行

**本轮提供了可信、可复算、无前视的四组收益对照机制，但得不出"AI 更会管理持仓"的结论。**

| 问题 | 当前答案 | 依据 |
|---|---|---|
| 动态持仓管理是否优于原始退出？ | **不确定，样本量改变排名**。200 笔 C（分批+移动止损）-23.87 优于 A -28.01、B -25.36；但 40 笔 C -4.21 最差 | 同一机制、不同样本数结论相反 |
| AI Position Manager 是否优于确定性 Manager？ | **没有证据**。D 组 507/507 次模型调用成功但**全部 HOLD、0 次管理动作** | `paired_r20261122_ai40_analysis.json` |
| 那 D 和"固定持有"有什么区别？ | **几乎没有**。逐事件配对 D-B：34 笔完全相同、6 笔更差、0 笔更好 | `paired_diffs["D-B"]` |

这不是策略失败证明，是**样本与信号不足**：入场事件本身在 60 天样本上普遍亏损（四组 200 笔净收益全负），
AI 又选择全部不动，所以没有"管理能力"可供检验。

### 有效性边界（必须随结果一起读）

1. **事件重叠**：40 笔 146 对观察窗重叠（18.7%），200 笔 978 对（4.9%）。重叠交易不是独立样本，置信区间需折减。
2. **两个 AI run 事件集不同**：`r20261122_ai`（旧分层规则）与 `r20261122_40b`（修正分层）的入场事件不一致，
   **不能跨 run 比较收益**；只有 run 内 A/B/C/D 配对有效。已加 `events_fingerprint` 守卫，
   并用修正分层重跑 `r20261122_ai40b`，完成后才能与 40b 同事件集对照。
3. **无历史新闻**：所有 D 组决策都在 `NEWS_UNAVAILABLE` 下做出，未检验"新闻反转导致退出"。
4. **AI 推理费用未计入净收益**：507 次调用的 token 成本尚未折算进 D 组，计入后 D 只会更差。
5. **入场事件整体亏损**：60 天里四组 200 笔净收益全负，说明当前 EMA20 入场规则无扣费优势；
   这是入场问题，不是持仓管理问题——两者已按用户要求拆成两条独立实验线。
