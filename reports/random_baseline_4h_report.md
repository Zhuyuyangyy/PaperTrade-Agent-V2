# OpenAlpha R0-4h — 4h 框架随机基线报告

分支 `audit/v3-acceptance-fixes`｜版本 `R0-4h-v1`｜生成 2026-11-23
**零联网**：4h 数据由本地 1h 缓存聚合（factor=4，缺口 0），未访问 `fapi.binance.com`。

---

## 结论先行

**4h 也不行，而且比 1h 更差。我上一轮「把框架搬到 4h」的建议被这个实验否掉了。**

| 指标 | 1h（R0-v1） | 4h（R0-4h-v1） |
|---|---|---|
| 冻结策略净收益 | +5.52 | **−4.73** |
| 研究集 / 样本外 | +7.87 / −2.35 | +1.21 / **−5.94** |
| 0bps 成本下净收益 | +12.73 | **+0.14** |
| 0bps 成本下样本外 | −0.56 | **−4.50** |
| 成交笔数 | 34 | 27 |
| 时间暴露率 | 1.66% | 4.77% |
| 完整流程随机对照 p | 0.4110 | **0.6815** |

「成本占 ATR 只有 14.9%」是真的（1h 是 30.8%），但**成本低不等于能赚钱**。
4h 把成本压力降了一半，同时把样本量和统计功效也降了，净效果是更差。

## 一、口径

| 项 | 值 |
|---|---|
| 数据 | 1h 缓存聚合 4h，4,380 根（2024-11-23 12:00 → 2026-11-23 12:00），**缺口 0** |
| ATR14（4h） | 中位 **120.7 bps**（P25 94.9 / P75 156.6） |
| 信号 | funding `delta` + `z ≥ 2.5`，38 个（与 1h 同一批时刻） |
| **主口径参数** | **stop 2.0×ATR / trail 1.0×ATR / start 1.0×ATR / hold 24 根（=4 天）** |
| 参数来源 | **先验网格中心，非优化结果** |
| 成本 | 往返 18bps（4 手续费 + 5 滑点，单边） |
| 单仓 | `busy_until`，38 信号 → **27 成交**（11 笔因持仓期撞单被挡） |
| 研究集切点 | bar #3066（= 1h 的 #12264，同一时间点） |
| 种子 | 20261123，2,000 次 |

**为什么不做参数优化**：E3 已证明 4h 的参数扫描能被置换检验否掉（p = 0.522）。
再扫一次只会把选择偏差当优势。主口径用先验中位，另附 18 组网格**全分布**，
让结论不依赖任何单点选择。

但这点信息不足以超过随机方向的运气。

**17/18 组研究集为正（中位 +6.06），18/18 组样本外为负（−3.38 ~ −8.92）。**

两个读数：

1. **研究集的正收益是结构性的，不是参数找出来的**——几乎任何参数都正，

   它会让任何参数看起来都有效。
2. **`hold=48` 普遍比 `hold=24` 高 4~6**，但样本外完全相同。因为延长持有只改变
   最后那一笔的浮盈，不改其它交易的路径——**这是纯账面美化，不是优势**。

## 五、成本敏感性：0bps 也不赚

| 往返 bps | 净收益 | 研究集 | **样本外** | 占 ATR |
|---|---|---|---|---|
| 0（假设） | **+0.14** | +4.64 | **−4.50** | 0% |
| 8（假设） | −2.03 | +3.11 | −5.14 | 5.0% |
| 12（假设） | −3.11 | +2.35 | −5.46 | 7.5% |
| **18（实测）** | **−4.73** | **+1.21** | **−5.94** | **11.2%** |
| 24（假设） | −6.36 | +0.06 | −6.42 | 14.9% |
| 30（假设） | −7.98 | −1.08 | −6.90 | 18.7% |

**0bps 时全样本净收益 +0.14——基本打平，但样本外仍是 −4.50。**

对比 1h：0bps 时全样本 +12.73、样本外 −0.56。
**4h 在研究集和样本外都明显差于 1h。**

结论：4h 的失效不来自成本。成本从 0 加到 18bps 只是把本来就接近零的期望压成负的；
真正的问题是**信号在样本外没有 edge**，与周期无关。

## 六、为什么 4h 更差：固定名义价值放大了风险

| 项 | 1h | 4h | 比值 |
|---|---|---|---|
| 止损距离 | 1.5 × 58.4bps = 87.6bps | 2.0 × 120.7bps = 241.4bps | **2.76×** |
| 单笔最大亏损（notional 100） | 0.876 | 2.414 | 2.76× |
| 成交笔数 | 34 | 27 | 0.79× |
| 平均持仓 | 8.4h | 30.4h | 3.61× |
| 时间暴露率 | 1.66% | 4.77% | 2.87× |

**同样的 100 USDT 名义价值，在 4h 上承担的单笔风险是 1h 的 2.76 倍。**
这不是 4h 的错，是仓位口径的错——**固定名义价值 = ATR 越大杠杆越大**。

做风险平价换算（notional 缩到 100 / 2.76 = 36.3）：

```
4h 净收益 −4.7334 × 0.363 ≈ −1.72
```

**仍然是负的。** 风险定仓改变亏损幅度，改变不了符号。

同时 4h 的持仓长 3.6 倍，单仓约束挡掉更多信号（38 → 27，挡 11 笔，比 1h 挡 4 笔多），
样本量进一步缩小，统计功效下降。

## 七、与 1h 的对照总结

| 判据 | 1h | 4h | 谁更好 |
|---|---|---|---|
| 冻结策略净收益 | +5.52 | −4.73 | 1h |
| 样本外 | −2.35 | −5.94 | 1h |
| 0bps 全样本 | +12.73 | +0.14 | 1h |
| 0bps 样本外 | −0.56 | −4.50 | 1h |
| 成本占 ATR | 30.8% | **11.2%** | 4h |
| 完整流程随机对照 p | 0.4110 | 0.6815 | 1h（更接近显著） |
| 真实值在随机分布中的百分位 | 58.9 | **31.9** | 1h |
| Sharpe（按笔） | +0.081 | −0.063 | 1h |

**成本维度 4h 赢，收益维度 1h 全赢。** 说明「成本占 ATR 低」是个**必要但不充分**条件——
它能排除 5m/15m，但不能证明 4h 可行。

## 八、结论

1. **4h 框架下的随机入场期望：**
   先验参数下 27 笔净 −4.73（每笔 −0.175）；0bps 成本下 +0.14，样本外 −4.50。
   随机方向 + 18 组选参数的中位是 **+6.91**——**比真实策略高 5.7**。

2. **funding 信号在 4h 上没有优势，甚至低于随机中位数**（第 31.9 百分位）。
   18 组网格全部样本外为负，且研究集几乎全正——这是「行情红利被误认为策略优势」的典型形态。

3. **「搬到 4h」这个方向到此为止。**
   成本压力确实降了（30.8% → 11.2%），但样本量、单笔风险、统计功效同时恶化，
   净效果是更差。1h 与 4h 两条路都走完了，结论一致：**问题不在周期，在信号没有 edge。**

## 九、下一步（不再是换周期）

| 优先级 | 动作 | 理由 |
|---|---|---|
| 1 | **换资产**：同一套 funding 信号测 ETH/SOL 等永续 | BTC 的资金费率最有效（套利最充分），换资产可能反而有信息 |
| 2 | **换信息源**：清算数据 / 订单簿失衡 / 基差 | 价格和资金费率都是「已被充分定价」的信息 |
| 3 | **改交易类型**：从方向性转向执行/做市 | 若 6 个信号家族 × 2 个周期全败，应怀疑「方向性交易」这个前提本身 |
| ✗ | ~~继续换周期（2h/6h/8h）~~ | 1h 与 4h 已覆盖成本曲线的两端，中间不会更好 |
| ✗ | ~~在 4h 上调参~~ | 18 组样本外全负，调参只会拟合研究集 |

**四年数据（等 17:07 解封）的用途已经改变**：不是用来把 p 值压低，
而是用来验证「1h 与 4h 的研究集正收益是否为特定行情的偶然」。
若四年数据下样本外仍为负，这套框架应整体废弃。
