分支 `audit/v3-acceptance-fixes`。零 API 成本（公开端点 + 本地缓存）。
**不接 Demo、不用真实资金、未合 PR #26。**

## 结论先行

**没过第 2 关（p = 0.10 > 5%），但它和 EMA 完全不是一类东西。**

| | EMA20 穿越（E3） | **资金费率顺势（E4）** |
|---|---|---|
| 真实研究集成绩 | +3.6543 | **+2.6316** |
| 置换检验**中位数** | **+4.1073**（真实低于中位） | **-7.6885**（真实远高于中位） |
| p 值 | 0.5220 | **0.1000** |
| 判读 | 连随机都不如，纯优化运气 | **处在噪声分布约 90 分位，有微弱信号迹象** |

一句话：**EMA 是假的；资金费率可能是真的但太弱，而且最近 7 个月是亏的。两个都不能用。**

费率分布：中位 **+0.0045%/8h**，p95 +0.0100%，max +0.0724%。

## 二、第一个必须说的事实：carry 小到可以忽略

这套策略名义上是"收资金费"，实测 108 笔累计 carry 只有 **+0.0181 USDT**（名义 100 USDT/笔）。

原因很直接：中位费率 0.0045%/8h ≈ 年化 4.9%，而平均持仓 12.9 小时只经历 1–2 次结算。
**在 BTC 永续上，"收资金费"这条经济逻辑根本撑不起一个策略**——它顶多是个零头。

真正决定盈亏的是价格方向，所以这实质是一个**方向性信号**，不是 carry 套利。

## 三、方向反了：顺势优于拥挤反向

我原本的假设是"高费率=多头拥挤→做空"。数据说反了：

| 配置 | 笔数 | 研究集 | 样本外 | 胜率 |
|---|---|---|---|---|
| z≥2.0 **反向**（做空拥挤） | 108 | -35.26 | -16.07 | 40.74% |
| z≥2.0 **顺势**（跟随拥挤） | 107 | **-7.46** | **+5.48** | **64.49%** |
| z≥2.5 反向 | 41 | -8.52 | -4.98 | 43.90% |
| z≥2.5 **顺势** | 42 | **-5.88** | **+3.99** | **61.90%** |

顺势的胜率高出 20 个百分点。经济解释也说得通：**资金费率上升往往伴随趋势加速**
（多头愿意付更高成本继续持有），而不是趋势耗尽。

但注意：**胜率 64% 仍然净亏**——赢的次数多，每次赢得少；输的次数少，每次输得多（止损 1.5 ATR）。

## 四、72 组全因子网格：只有 1 组为正

网格 = z(3) × stop(3) × trail(2) × hold(2) × 方向(2) = **72 组**。
方向必须进网格，否则等于预设结论。

| 2 | z2.5-stop1.5-trail1.0-h24 | 42 | -0.6212 | -5.2941 | 40.48% |
| 3 | z2.0-stop2.5-trail0.75-h72-flip | 108 | -1.0221 | +4.4708 | 75.00% |
| … | … | | | | |
| 71–72 | z1.5 系列 | 280–317 | **-49.6 ~ -50.6** | -22 ~ -28 | ~47% |

- **研究集为正：1/72 = 1.4%**（对比 EMA 的 7/16 = 43.75%）
- 唯一为正的那组，样本外 **-5.26**
- z≥1.5 的宽阈值组亏得最惨（-50），因为信号太频繁、手续费吃光

## 五、第 2 关：置换检验（120 次 × 72 组全扫）

每次置换都**重跑整条流程**：打乱价格收益 → 重新生成资金费率信号（费率表保持不变）→ 重扫 72 组 → 取研究集最优。

| 项 | 值 |
|---|---|
| 真实最优 | **+2.6316** |
| 置换**中位数** | **-7.6885** |
| 置换均值 | -6.83 |
| p90 | +3.3740 |
| p95 | +6.9575 |
| max | +12.5053 |
| ≥ 真实的次数 | 12 / 120 |
| **p 值** | **0.1000 → FAIL_OVERFIT** |

**真实成绩在 120 条随机行情里排第 13 名（约 90 分位）。**
这比 EMA（排第 523 名 / 1000，低于中位）强得多，但门槛是 5%，10% 不够。

## 六、为什么还是不能用

1. **p = 0.10 未过门槛。** 按预定规则，不过就是不过，不能因为"接近"就放行。
2. **样本外 -5.26。** 研究集 +2.63、最近 7 个月 -5.26，方向不一致——
   如果优势是真的，不该在最近的样本上系统性亏钱。
3. **唯一为正的组是 42 笔、止损 1.5 ATR 的窄配置**，而网格里 71 组都亏。
   一个只在一格成立的策略，正是「尖刺」的定义。
4. **家族级选择偏差没被校正。** 我是在 EMA 失败后才换到资金费率的，
   这个"换家族"的动作本身也是多重比较，置换检验只校正了家族内部。

## 七、可复用的两个副产品

1. **置换分布的形状本身是信息**：EMA 的随机最优中位数是 **+4.11**（正），
   资金费率的随机最优中位数是 **-7.69**（负）。
   这说明**在随机行情上，趋势跟随式退出会被反复打损，而资金费率顺势的退出结构不会**——
   也就是说后者的收益不全来自"优化挑出来的"。
2. **数据管道升级**：`load_klines()` 支持任意周期 + 超时重试 + 缺口校验，
   `load_funding()` 支持分页缓存。2 年数据一次拉取 21 次请求，之后零网络。

## 八、下一步（按性价比排序）

## 九、边界

- 单标的（BTCUSDT）、2 年、1h 粒度；未测 ETH/其他合约；
- 置换只打乱价格、保留费率时序，检验的是"价格对费率的响应是否真实"，
  不检验费率本身的可预测性；
- 120 次置换的 p 值分辨率为 1/120 ≈ 0.008，0.10 距门槛较远，加次数不会翻盘；
- carry 用真实费率逐次结算（已用测试锁定符号：多头付正费率、空头收）。
