# OpenAlpha V3 — 实验 E3：反过拟合验证（参数高原 + 置换检验）

分支 `audit/v3-acceptance-fixes`。零 API 成本，纯本地。**不接 Demo、不用真实资金、未合 PR #26。**
方法论取自「策略工厂 4 道关」的前两关（与模型无关的标准做法）。

## 结论先行

**E2 里那个“4h 转正”的结果被否掉了。它是优化出来的运气，不是市场规律。**

| 检验 | 结果 |
|---|---|
| 参数高原（4h） | **MIXED**：16 格里 7 格为正，最优格同行同列邻居仅 4/6 为正 —— 是一小块凸起，不是高原 |
| 参数高原（1h） | **SPIKE**：**0/16 格为正**，任何参数组合都亏 |
| **置换检验（4h, 1000 次）** | **p = 0.5220 → FAIL_OVERFIT** |

置换检验的核心数字：

| 项 | 值 |
|---|---|
| 真实数据最优（32 组参数里挑最好） | **+3.6543**（stop 2.5 / trail 0.75 / start 1.0，17 笔） |
| 假行情最优的**中位数** | **+4.1073** ← 随机数据比真实数据还高 |
| 假行情最优的 p95 | +18.0011 |
| 假行情最优的最大值 | +36.3787 |
| 1000 次里成绩 ≥ 真实的次数 | **522 次** |

**换句话说：在打乱涨跌顺序的随机行情上，用同一套流程扫 32 组参数，中位数就能拿到 +4.11，
比真实数据辛苦挑出来的 +3.65 还高。** 这已经不是“优势不显著”，是**没有优势**。

## 一、参数高原：真优势应该是平地，不是尖刺

### 4h（研究集净收益，行=初始止损，列=移动止损距离，启动=1.0 ATR）

| stop \ trail | 0.5 | 0.75 | 1.0 | 1.5 |
|---|---|---|---|---|
| 1.5 | -18.25 | -16.81 | -18.14 | -14.44 |
| 2.0 | **+2.66** | **+3.54** | -0.32 | -0.33 |
| 2.5 | **+2.61** | **+3.65** | **+1.33** | -0.47 |
| 3.0 | +0.24 | +1.38 | -0.66 | -1.93 |

- 正收益 7/16 = 43.75%，最优格邻居 4/6 为正 → **MIXED**
- 有一块 2×2 的小凸起（stop 2.0–2.5 × trail 0.5–0.75），但**四周立刻转负**
- `stop 1.5` 整行是 -14 到 -18：**止损放窄 0.5 个 ATR，策略直接崩掉**

### 1h（同口径）

16 格**全负**，最好的一格 -4.26 → **SPIKE**。
E2 里 1h-trail 看起来“最好”（-14.61），但在参数网格里它是**均匀地亏**，没有任何可站住的位置。

### 样本外的 16 格完全相同

4h 的样本外每个格子都是同一组数（2.5733 / 2.3890 / 1.9916 / 1.1982，按 trail 分），
因为样本外只有 **2 笔**交易，止损参数根本不起作用。
**样本外在这个实验里不提供任何判别力**，不能作为“验证通过”的依据。

## 二、置换检验：怎么做的

1. 取真实 5m 序列的 close 对数收益，随机打乱顺序；
2. 平移到与原序列**总收益相同** → 起点终点价格完全一致（84113.40 → 60822.70）；
3. 每根 K 线 OHLC 按同一比例缩放 → 保持自身几何关系与 OHLC 自洽；
4. 在假行情上**重跑整条流程**：重新生成 4h 信号 → 重扫 32 组参数 → 取研究集最优；
5. 重复 1000 次，统计“≥ 真实成绩”的比例。

置换质量已核验：收益均值/标准差与真实**完全相同**（-1.792e-05 / 1.298e-03），
lag1 自相关从 **-0.01102 打到 -0.00115**（规律确实被打碎），OHLC 不自洽 0 根，同种子可复算。

`p = 522 / 1000 = 0.5220`。文章给的门槛是 p ≤ 5%（前推 1 年）或 1%（2 年以上），
**0.522 差了整整一个数量级。**

## 三、这轮的另一个收获：噪声基线

在 32 组参数的网格上，**随机行情的“最优成绩”分布**是：

| 分位 | 值 |
|---|---|
| 中位数 | +4.11 |
| p90 | +14.70 |
| p95 | +18.00 |
| 最大 | +36.38 |

这给我们一个可复用的判据：**在本实验口径下（100 USDT 名义、60 天、32 组参数），
任何单点回测结果低于 +18 都在噪声范围内，不能当作优势。**

E2 的 +3.65 和 +2.39 都远在这个门槛之下。

## 四、代码

- `research/experiment/validate.py`
  - `shuffle_bars()`：端点保持 + 分布保持 + 自相关打碎的置换行情生成；
  - `grid_variants()`：32 组全因子网格（stop × trail × start）；
  - `plateau()`：热力图 + 正收益占比 + 最优格邻居判据（PLATEAU / MIXED / SPIKE）；

- 新增 4 条测试：端点/分布保持、自相关被打碎且同种子可复算、网格全因子、p 值范围。

## 五、对 OpenAlpha 的意义

1. **EMA20 穿越这个入场规则，在所有测过的周期与退出组合上都没有优势。**
   1h 全负、4h 只有一个随机的凸起、5m 成本占 ATR 134%。**问题在信号，不在持仓管理，也不在 AI。**
2. **E2 的“4h 转正”正式作废。** 它通过了样本外，却被置换检验否掉——
   这正说明“样本外只做一次”远远不够，尤其样本外只有 2 笔时。
3. **继续调这批参数是浪费。** 按文章的判据，这个策略家族的活已经干完了：
   第 1 关（样本内好看）勉强过，第 2 关（置换）挂掉，直接淘汰。
4. **下一步应该换信号，不是换参数。** 需要的是有经济解释的东西
   （资金费率极值、跨期基差、清算瀑布后的均值回归、成交量异常），
   而不是又一条均线交叉；并且任何新信号都必须先过这一关置换检验。
5. **AI 的定位要再往后放。** 在找到过得了第 2 关的信号之前，
   讨论 AI 能不能管好仓位没有意义——没有正期望，管理只能减少亏损速度。

## 六、边界

- 单标的（BTCUSDT）、60 天、单一时段；结论只否定**这个信号 + 这个参数族**，不否定所有策略；
- 置换打乱的是收益顺序，保留了波动幅度分布，但破坏了波动聚集与时序结构，
  这对趋势类策略是偏严格的检验（趋势策略本就依赖顺序）——**但正因为严格，结论才可信**；
- 1000 次置换的 p 值分辨率为 0.001，0.522 远离门槛，不需要更多次数；
- 未做第 3、4 关（滚动前推、前推置换）：第 2 关已挂，按流程无需继续。
