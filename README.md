## 仪器：这个项目真正的资产

赚钱线停了，测量层是可复用的。四件东西：

### 1. Path-aware 回放器（`research/audit/pathsim.py`）

逐 bar 回放，同一根 K 线内止损和止盈同时触及时**默认判止损**，乐观读法并列打印。这不是学术洁癖——CascadeFader 的仓库自己记录过：用"是否触及过止盈价"分析得到 +469%/91% 胜率，改成路径回放后是 +132%/PF 1.62。**同一批信号，差 3.5 倍。**

信号在**下一根 K 线开盘**成交（本 bar 收盘才知道信号，bar 内成交就是前视）；未成交的信号被计数，不丢弃。

### 2. 随机入场对照组（`research/audit/runner.py`）

每个策略对照"同币、同时刻、同退出规则、随机 bar 入场"（固定 seed 可复现）。**打不过自己对照组的策略，是有论文的巧合，不是策略。** TrendRider 8468 笔 PF 0.84、CascadeFader PF 1.12 都过不了这关。

### 3. 成本模型（`research/replay/costs.py`）

用池深度反推冲击成本 + LP 费 + 固定链上费，替代配置里的常数。实测：池深中位 $799k 时 $100 单往返 60bps（其中 50bps 是 LP 地板，与池深无关）；配置里那个 120bps 其实是给 $1,000 单定的价——**尺子用错了地方，不是数写错了。**

### 4b. maker 成交模型（`research/audit/pathsim.py` 的 `fill_model`）

见上文 FundingRate 一节：taker/maker 的差别不止费率，还有成交条件、成交价、和“信号根本没变成交易”的概率。

### 5. 影子价格（`research/replay/labels.py`）

没买的候选也记账：5m/15m/30m/1h 前向曲线。没有它就算不出"经过筛选的候选收益更高"这个断言是否成立——而那正是每个 agent 过滤规则的隐含承诺。

## 外部策略审计（`research/audit/`）

用审自己的同一套仪器，审 GitHub 上找来的三个策略。阈值全部用作者默认值，未做任何调优。

| 策略 | 来源 | 笔数 | 胜率 | 笔均净 | PF | vs 随机对照 | 判定 |
|---|---|---|---|---|---|---|---|
| CascadeFaderV1 | IvPalmer/Master-Trader | 189 | 69% | +0.21% | 1.12 | +0.42% | ❌ 输给对照 |
| TrendRider | darkvolg/trendrider-strategy (MIT) | 8468 | 52% | -0.41% | 0.84 | -0.02% | ❌ 大样本负期望 |
| FundingRateEnhanced | realm520/FreqBot | 2095 | 43% | -0.03% | 0.88 | -0.05% | 🟡 唯一候选 |

### 仪器校准（本节是上面表格可信度的来源）

CascadeFader 的仓库公布了 3.3 年实验室数字：PF 1.62，按 per-pair edge 精选 13 个币。我们用**他们公布的排除规则**（排除 BCH/DOGE/XRP/LINK/TRX）重建名单、同样窗口重放，得到 **PF 1.12**——方向和量级吻合，我们更保守。差异来自他们名单自带的选择过拟合。**仪器读得出同一个信号，也读得出精选名单的虚高。**

### FundingRate：三档费率 × 两种成交模型（2095 笔信号，两种 bar 假设结果一致）

| 成交方式 | 笔均净 | PF | vs 随机对照 |
|---|---|---|---|
| taker 5bps/边（真实零售价） | -0.046% | 0.80 | **+0.110%** |
| maker 2bps/边，理想成交 | +0.014% | 1.07 | **+0.007%** |
| **maker 2bps/边，真实成交** | **-0.001%** | **1.00** | **+0.027%** |

最后一行是决定性的：把 maker 单当**限价单**处理（只在价格**穿越**挂单价时成交，成交价=挂单价），2095 个信号里 107 个从未成交——**那 15bp/笔的 maker 优势正好被成交不确定性吃光**，PF 落在 1.00。

但注意第三列：它在**每一种**执行假设下都赢随机对照。费率信号里确有价格之外的信息——问题是信息刚好薄于执行摩擦。**判定：不值得 dry-run（期望 ≈0），除非有费率折扣或队列优势。这是我们自己的仪器在一小时内推翻自己上一版结论的一次。**

### 5. 成交模型（`pathsim.py` 的 `fill_model="maker"`）

限价单不是“更便宜的市价单”，是另一种东西：成交需要价格**穿越**挂单价（触及不算）、成交价=挂单价（价格改善）、没穿越就整笔不存在。止损保持市价单——挂着不成交的止损恰恰是最需要它成交的那种订单，把它建模成限价单是给策略涂脂抹粉。

## 市场化验证：从回放到真钱的阶梯（`research/live/`）

“敢不敢上真钱”的正确形式不是勇气，是一套**事前写死规则的裁判**。`research/live/ladder.py` 是一个五级状态机——`replay → dryrun → probe → pilot → scale`——不接交易所、不放一笔订单，只回答一个问题：**一个策略要经过多少证据才配碰钱，以及什么情况下自动被拿下来。**

四条铁律，全部有测试守着：

1. **规则事前写死**：每层的样本量/PF/笔均净/胜率/未成交率/回撤门槛来自配置，运行中不改
2. **降级自动，升级不自动**：触发器一响就降级或停机，不问任何人；升级必须人工确认——**机器可以自己失去信心，不能自己获得信心**
3. **停机优先于一切**：连亏 8 笔、对账差一笔、行情断 5 分钟，任何一条立即冻结，与统计表现无关
4. **每个判定带理由**：说不出为什么行动的审计是演戏

降级的样本门槛数**信号**（未成交本身就是执行证据），升级数**成交**——失去信心比获得信心容易。FundingRate 若要走这条路，现状是：replay 层 PF 1.00，卡在第二级门口。

## 新战线：A 股可转债折价审计（`research/astock/`）

外币市场的结论（对手是毫秒级做市商、成本 60-100bps）把人逼回主场。A 股改掉了杀死策略的那个变量：**往返成本 ~2bps（佣金万 1 双边、可转债免印花税）**，且可转债是 T+0——当天买当天能卖，日内闭环。

审计的问题不是“能不能涨”，是：**折价（转股溢价率 < 0）出现时，买转债等收敛，扣掉成本后还剩什么？** 这是结构性错配，不是方向预测，和本项目“收租而非猜涨跌”的结论同构。

- 信号：转股溢价率 < -1%/-2%/-3%/-5%（四档同时测，出曲线不出点）
- 入场：信号日**次日**收盘（日线数据下收盘价信号最早可成交的价格，比盘中成交保守一天，已披露）
- 持有：1/3/5 日；成本：佣金 1bp/边
- 对照：**同一批券**的随机入场日（固定 seed），同持有期同成本
- 数据：akshare——转股价映射（同花顺，973 只）、转债日线（新浪）、正股日线（新浪，当前）
- **数据窗口的现实**：新浪转债序列各只停在 2023~2025-07 不等，正股是当前的。审计用两者重叠区间并在报告里写明，不装作是全样本

### 结果（509 只券 · 334,639 个债券日 · 55,412 个信号 · 2023-07~2025-07 窗口）

| 折价深度 | 持有 1 日超额 | 持有 3 日超额 | 持有 5 日超额 |
|---|---|---|---|
| > 1% | +0.002% | -0.036% | -0.099% |
| > 2% | -0.004% | -0.050% | -0.116% |
| > 3% | -0.007% | -0.059% | -0.129% |
| > 5% | -0.005% | -0.063% | -0.140% |

（超额 = 信号组笔均 − 同券随机入场对照组笔均，均已扣 2bp 佣金）

**判定：无 edge。** 1 日超额在 ±0.5bp 内——噪声；3/5 日为负且越持有越差。这不是“成本杀死策略”（成本只有 2bp，是加密的 1/30），是**折价本身不收敛**：买入后等下去，价差不会回来。

**为什么价差不回来（市场结构的原因，不是我们的模型缺陷）**：折价套利的闭环是“买转债 → 转股 → 卖正股”，而**转股得到的股票 T+1 才能卖出**——闭环至少隔一夜，有隔夜风险，所以折价可以长期存在而不被抹平（信号频率 16.6%，平均每 6 个交易日一次）。散户能执行的“买入等收敛”路径，等的就是这个不会发生的收敛。

**这次否定的意义**：它和加密线的否定方式不同——加密是“有 edge 但被成本吃光”（FundingRate 赢对照），可转债是“错配真实存在但散户的执行路径够不着”。两者共同刻画了边界：**这个市场上看得见的钱，分别在成本对面和制度对面。**

```bash
python -m research.astock audit --limit 60    # 先跑 60 只
python -m research.astock audit --limit 0     # 全量（732 只老券，约 20 分钟）
```

## 产品化：策略证伪引擎（`research/verify/`）

赚钱线停了，仪器活着——而且被市场调研证明有真实需求（`docs/market-scan-2026-10-29.md`：backtest→实盘中位差 -14.3pp 是行业第一痛点，而市面服务只会"画曲线"）。`research/verify/` 把整个项目淬炼出的四件仪器打包成一个 CLI：**输入一份策略 spec，输出一份试图杀死它的报告。**

```bash
python -m research.verify --demo --out report.md          # 内置演示（真实 BTC 1h 缓存数据）
python -m research.verify --spec spec.json --candles klines.csv --signals sig.csv --out report.md --json
python -m research.verify --list-market                   # 本地行情缓存里有什么
```

四件仪器，一个裁决：

| 仪器 | 回答的问题 |
|---|---|
| path-aware 回放 | 同一批信号，逐 bar 走价（bar 内 SL/TP 同现判 SL），最坏/最好口径并列——你赚的是价差还是假设？ |
| 成本敏感性 | 费率 ×1/×2/×5 重放——edge 付不付得起自己的 toll？（本项目实测：$100 单 60bps，其中 50bps 是 LP 地板） |
| 障碍可达性 | 止盈/止损位在持仓窗口内到底被摸到过几次——还是彩票结构？ |
| 随机入场对照组 | 同窗口同退出规则随机入场，bootstrap CI 比均值——打不过抛硬币的策略，绝对收益数字没有意义 |

**裁决不是分数，是事前证伪规则的判定结果**：`falsify_if` 写在 spec 里、先于任何数字存在（对照/证伪规则触发→FALSIFIED；样本不足→INCONCLUSIVE，不下结论；否则 NOT_FALSIFIED，并附"未被证伪≠被证实"）。报告固定含"未建模事项"一节——不知道仪器边界的人会滥用仪器。

样例报告（真实数据，RSI 抄底 BTC 策略 3 年 1310 笔）：`docs/verify-sample-report.md`——裁决 FALSIFIED：基线即亏损、×2 成本净 -610%、且**显著差于随机入场**（差值 -0.37%，95% CI [-0.70%, -0.03%]）。spec 模板：`research/verify/samples/demo_spec.json`。

**案例矩阵**（`docs/cases/`，四个事前声明变体全部发布）：抄底 BTC / 追涨 BTC / 抄底 ETH / maker 限价成交，统一 29,347 根 1h futures 真实 K 线。三个被对照组击败，第四个 **+34% 三年曲线仍被判 FALSIFIED——统计上无法与随机入场区分（CI 跨 0），钱是 beta 不是 alpha**。引擎同时支持客户自带信号（CSV 进场 + CSV 信号退出）。

**方法论文章**（对外内容资产）：`docs/article-falsification.md`。**分发作战包**（Reddit/X/闲鱼/Toku 文案 + gate 规则 + 本人操作清单）：`docs/dist/`。

**测试**：`tests/test_verify.py` 36 个用例（spec 校验/数据加载/RSI/指标/障碍可达/对照组确定性/CLI 端到端）。修复了 pathsim 一个真 bug：maker 未成交单曾被同时计入 unfilled 和 open_signals，虚低成交率。

## 运维：这个系统活着的时候经历过什么

实验期间的真实事故与修复，全部有提交记录：

| 事故 | 根因 | 修复 |
|---|---|---|
| 整轮 0 代币，报 `ValueError: expected 2, got 1` | `_timed()` 失败返回 `{"error":...}`，四个 agent 先解包再判 ok，真实错误被第二层异常埋掉 | `BaseAgent._failed()` 统一面化错误 + 给下游留形状正确的空手 |
| 止损名义 -12%，实际成交 -12.2%~-21% | mark/exit 只在六 agent 轮次里跑，一轮 4-5 分钟，价格在两次检查间跳穿 | 独立 60 秒退出循环 |
| `database is locked` 锁风暴 | `_sample_equity()` 写了不提交，退出循环抱 WAL 写锁整分钟 | sample 后补 commit；失败轮 rollback；回归测试用第二连接验证 |
| 退出循环静默死 3.7 小时，数字冻结 | 看门狗靠查库判活，读取器竞争失败与"健康"无法区分 | 退出循环自写心跳文件；看门狗读文件不读库 |
| 每次扫描 2.8 个数据源报错 | `_get()` 遇 429 直接放弃，一次扫描连发 8 请求挂一个丢一个 | 429 重试 2 次 + 尊重 Retry-After + 退避 |
| 权益曲线全平 7.7 小时 | 本机 DNS 被污染 + TCP 重置（代理工具掉线），不是限流 | 面板加数据源健康度告警："曲线平是因为没行情，不是因为停了" |
| 五本账偶尔变四本 | 账本被瞬时锁占用时 feed `continue` 静默丢行 | `_unavailable()` 两条失败路径都列出行 |
| 看门狗同时跑两个 `once` 探针撞锁 | 探针产生真实轮次 | 轮次互斥锁（pid+时间戳，10 分钟接管） |
| 停止后循环反复复活 | `loop.sh` while true 守护 + 排队后台任务到点自启 | STOP 文件 kill switch（幂等） |
| 后台任务约 3 小时被系统回收 | 环境事实 | 主+副班双看门狗，故障窗口 30 分钟 |

**272 个测试，全部通过**（含 verify 引擎 36 个；`test_convertible` 因环境缺 akshare 跳过收集）。

## 最终判定

**这个项目证明了一套特定方法在特定成本结构下不成立，并且把"证明"本身做成了可复用的仪器。** 它不是一个亏钱的交易机器人——亏钱的机器人满街都是，能拿出证据链的没几个。

市场化验证的阶梯已经备好（`research/live/`）：规则事前写死、降级自动、升级需人、停机优先。今天没有策略够资格站上去——FundingRate 三档执行假设全赢对照但恰好被摩擦吃平（PF 1.00），这是仪器给出的最终答案，而阶梯是给下一个候选准备的。

**归档之后**：仪器没有跟着归档。`research/verify/` 把四件仪器产品化为"策略证伪即服务"——市场调研（`docs/market-scan-2026-10-29.md`）显示这是个人在这个生态里少数被验证有真实付费需求的方向：别人卖"收益率曲线"，我们卖"这条曲线是不是幻觉"。
