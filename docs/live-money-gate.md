## 0 · 现在的系统在做什么（先对齐认知）

「全系统权益 4470」**不是钱**，是 5 个独立虚拟账本的估值合计：

| 账本 | 虚拟本金 | 角色 |
|---|---|---|
| A 基线 / B 风控 | 1000 + 1000 | 指标策略对照组（容器未运行，冻结） |
| C 对照组 | 1000 | 同一批候选、纯 organic 排序 |
| D 链上跟单 | 500 | 跟踪链上钱包成交 |
| E 六 agent | 1000 | SEARCH→RISK→GMGN→JUDGE→FOMO→EXIT |

所有成交都是**虚拟撮合**：无钱包、无私钥、无签名、无交易所连接。真实资金投入：**0**。

## 1 · 放行前必须满足的门槛

### Gate 1 — edge 有证据（未达标）

回放引擎在**未参与调参的时间段**上，同时满足：

- [ ] 单笔期望收益 > 0（扣掉 120bps 往返成本后）
- [ ] 在 0 / 60 / 120 / 240 bps 四档成本假设下都成立（只在 0bps 成立的是手续费补贴）
- [ ] E − C 差 > 0 且方向稳定（六 agent 相对纯规则的优势）
- [ ] 消融测试：逐条关掉规则，表现不变的规则删掉
- [ ] 校准：JUDGE 分桶命中率随分数段上升（LLM 有区分度）

方向对（E−C = +20），但样本量离统计显著差得远。**这是数字游戏，不是证据。**
