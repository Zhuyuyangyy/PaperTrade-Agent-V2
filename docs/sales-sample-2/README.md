## 结论

**FALSIFIED — `edge_absent`**

在 20–300 分钟的持仓期上，这套信息集（Jupiter 的 organic 分、持币人数、
涨跌幅快照）**没有可交易的 alpha**。不是"参数还没调好"，是这套字段里
不存在能预测短期方向的东西。

第二死因：**`overfitting`（追高）**。评分把"已经涨过"当成优点，
于是系统性地买在每一段行情的顶部。

## 2. 六项检验

样本：1,251 个通过全部硬门槛的候选，其中 **539 个**有 20–300 分钟后的
前向标记（`candidates-forward.csv`）。

### 2.1 路径回放 —— 系统从不主动出场

86/101 的仓位是"时间到了"才平的，不是止盈也不是止损。
一个真正的 edge 会让仓位频繁触达目标；这里 85% 的仓位只是到期。

### 2.2 成本敏感性 —— 成本就是全部

TIMEOUT 组均值 -1.72%，往返成本假设 1.20%。
**两者相差 0.52 个点**，这就是选币的全部贡献，而且是负的。

### 2.3 障碍可达性 —— 止盈线在分布之外

+30% 的止盈在 101 笔里只触发了 **2 次**。原来设的是 +55%，触发 2 次；
改成 +30% 之后还是 2 次。目标定在一个极少到达的位置，
等于没有目标，只剩时间和止损两个出口。

### 2.4 随机对照 —— 评分对收益零预测力

| 按旧评分五等分 | n | 扣成本后均值 |
|---|---|---|
| Q1（最高 93–75） | 107 | **-0.40%** |
| Q2（75–71） | 107 | **+4.37%** |
| Q3（71–64） | 107 | **-2.04%** |
| Q4（64–60） | 107 | **+0.24%** |
| Q5（最低 60–52） | 111 | **-2.34%** |

**秩相关 IC = +0.081。** 分组结果不单调：最高分那一档是亏的，
第二档却是最好的。这不是"评分有噪声"，是"评分和收益之间没有稳定关系"。

### 2.5 分样本 —— 追高是唯一稳定为负的行为

| 1 小时涨幅 | n | 扣成本后均值 |
|---|---|---|
| < 0% | 143 | +4.20% |
| 0 ~ 5% | 195 | +0.46% |
| 5 ~ 15% | 131 | -1.85% |
| **> 15%** | **70** | **-6.78%** |

而旧规则实际成交的 70 笔里，占多数的正是 `score ≥ 52 且 1h ≥ 15%` 这一档。

### 2.6 参数网格 —— 出场参数只值 0.2 个百分点

用 347 条价格路径回放不同出场组合：

| 止盈 / 止损 / 超时 | 期望 |
|---|---|
| 55 / -12 / 180m | +1.90% |
| 30 / -12 / 180m | +2.04% |
| 20 / -18 / 120m | +2.01% |
| 12 / -18 / 90m | +1.92% |

**最好的和最差的只差 0.2%。** 调出场参数救不了这个策略，
因为问题在入场，不在出场。

## 3. 最要命的一段：同一规则，两种取样，正负翻转

这是整份报告里唯一"方法论"层面的收获，也是我们后来写进 SKILL.md 的那条铁律。

前向价格有两个来源：

- `scan-reuse`（79%）：下一轮扫描时又扫到这个币，顺手记下它的价格
- `jupiter-quote`（21%）：主动向价格接口单独询价

同一个规则——「买 1 小时在跌的币」——在两批样本上：

| 样本 | n | 扣成本后 | 正收益率 |
|---|---|---|---|
| 全部 | 143 | **+4.20%** | 65% |
| 只算"被再次扫描到的" | 117 | **+5.65%** | 71% |
| **只算独立报价的** | **26** | **-2.35%** | **38%** |

**+5.65% 变成 -2.35%，只因为换了取样方式。**

原因很简单：能被下一轮扫描再次扫到，本身就意味着这个币还活着、还在交易。
崩掉的币不会再出现在榜单上，于是它的亏损被系统性地排除在样本之外。
**这个 +4.20% 不是策略的 edge，是数据管道的幸存者偏差。**

如果只看全样本，我们会得出"买跌能赚 4.2%"的结论，然后拿真钱去验证它。
独立报价那 26 笔会告诉我们真相。

## 4. 诊断结论

| 结论 | 证据 | 处理 |
|---|---|---|
| `edge_absent` | 扣成本后中位 -1.58%；TIMEOUT 组 -1.72% ≈ 成本 | 该信息集不交易 |
| `overfitting`（追高） | `chg_1h > 15%` 组 -6.78%，独立报价样本 **-12.88%**（n=12） | 加硬性拒绝 |
| `barrier`（止盈不可达） | +30% / +55% 都只触发 2 次 | 止盈降到 30%，接受"赚小钱" |

## 5. 我们真的改了什么（不是建议，是已执行）

| 改动 | 依据 |
|---|---|
| 评分拆成 `quality`（是不是骗局）和 `timing`（现在是不是买点），各自设门槛 | 一个混合分让"流动性好但正在下跌"的币拿到 59 分 |
| `chg_1h > 15%` 直接拒绝（`ALREADY_RUN_UP`） | 该档位两个独立样本都是 -6.78% / -12.88% |
| 止盈 +55% → +30%，止损 -12% → -18% | 347 条路径回放；原止损线落在噪音带里 |
| 单笔 100 → 60 USDT，持仓上限 5 → 3 | 规则未验证前先降暴露 |
| 滚动 30 笔期望跌破 -0.5%/笔 自动停手 | 旧账按这个规则早就该停：最近 30 笔 -6.12%/笔 |
| 常驻循环 + 心跳 + 陈旧价格不计入完整权益 | 五笔持仓曾挂着六天前的价格，账面显示 905，实际 824 |

**改完之后的诚实结论**：即便如此，最严格的组合（timing ≥ 85 且 quality ≥ 55）
在 112 个独立报价样本上仍然只有 **-0.30%/笔**。

所以我们把账户降为观察仓，而不是宣布"修好了"。

## 6. 复现

```bash
# 1. 候选与前向收益（本目录附带，539 行）
head -3 candidates-forward.csv

# 2. 用这份 CSV 重算 IC 与分组（不需要数据库）
python - <<'EOF'
import csv, statistics
rows = list(csv.DictReader(open("candidates-forward.csv", encoding="utf-8")))
def mean(xs): return sum(xs)/len(xs)
# 扣 120 bps 往返成本
r = [float(x["forward_return_pct"])/100 - 0.012 for x in rows]
print(f"n={len(r)} 扣成本均值 {mean(r)*100:+.2f}% 中位 {statistics.median(r)*100:+.2f}%")
for lo, hi, tag in [(-100,0,"1h<0"),(0,5,"1h 0-5"),(5,15,"1h 5-15"),(15,999,"1h>15")]:
    g = [float(x["forward_return_pct"])/100 - 0.012 for x in rows
         if lo <= float(x["chg_1h_pct"]) < hi]
    if g: print(f"  {tag:<9} n={len(g):>3} {mean(g)*100:+.2f}%")
EOF

# 3. 独立报价子样本（去掉幸存者偏差）
python -c "
import csv, statistics
rows=[x for x in csv.DictReader(open('candidates-forward.csv',encoding='utf-8')) if x['mark_source']=='jupiter-quote']
r=[float(x['forward_return_pct'])/100-0.012 for x in rows]
print(f'n={len(r)} 扣成本 {statistics.mean(r)*100:+.2f}%')"
```

## 7. 这份报告没有证明什么

- 它**没有**证明"meme 币不能交易"。它证明的是"这套公开字段不能预测 20–300 分钟的方向"。
- 它**没有**排除运气。101 笔的样本不大，但 -17.23% 配上 23.8% 胜率
  和 36% 的平衡线，很难归因于运气。
- 它**没有**说新规则能赚钱。改完之后独立报价样本仍是 -0.30%。
- `candidates-forward.csv` **仍带 79% 的幸存者偏差**，所以它复现得出
  全样本的 +4.20%，也能复现独立报价子样本的 -2.35%。**看第二个。**
