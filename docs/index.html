The Problem

01市面服务只会「画曲线」，我们负责回答曲线是不是幻觉

每个卖机器人的仓库都有一条漂亮曲线。行业实测：22 个零售 bot 里 17 个与指数相关性 > 0.8——牛市里随机入场也赚钱，这条曲线卖的是 beta，包装成 alpha。样本内过拟合是回测失效的第一死因，而绝大多数回测工具对此一言不发。

我们的立场：这个工具杀死策略，不生产策略。如果你的回测是真的，这份报告是你最好的营销资产；如果它是幻觉，你省下的是一整年订阅费。我们同时披露仪器的边界——报告固定含「未建模事项」一节，未被证伪 ≠ 被证实。
Instruments

02六台仪器，一个裁决

全部规则事前声明：证伪阈值写死在 spec 里、先于结果存在；跑完不分好坏全部发布。

#1Path-aware 回放

同一批信号逐 bar 走价，bar 内止损/止盈同触默认判止损，最坏/最好口径并列——你赚的是价差还是假设？实测过同一信号差 3.5 倍。

#2成本敏感性

费率 ×1 / ×2 / ×5 重放：edge 付不付得起自己的 toll？费率翻倍就翻车的曲线，是在给交易所打工。

#3障碍可达性

止盈/止损位在持仓窗口内到底被摸到过几次——还是止损从未工作的彩票结构？

#4随机入场对照组

同币、同时刻、同退出规则、同成本，随机 bar 入场（固定 seed 可复现）。打不过抛硬币的策略，绝对收益数字没有意义。

#5Walk-forward

窗口切 N 折，样本内/样本外各跑完整电池，同一批事前规则在样本外复判——样本外被证伪 → 整体 FALSIFIED。只在看得见的地方成立的 edge 不是 edge。

#6参数敏感性网格

事前声明的退出参数全网格重放：只有个别格子为正 → 打过拟合标记。edge 只在一小撮参数组合下存在，是曲线拟合不是 edge。

Case Matrix

04同一台引擎，四种死法

四个事前声明的策略变体，同一窗口（Binance 1h futures，29,347 根/币，2023-06-24 → 2026-10-28），跑完不分好坏全部发布——包括看起来很赚钱的那个。

案例假设成交净收益vs 随机对照裁决
case1 抄底 BTCRSI<30 做多，均值回复1310-505.65%refuted -0.37%，CI[-0.70,-0.03]FALSIFIED
case2 追涨 BTCRSI>70 做多，动量延续1638+34.35%unproven +0.03%，CI 跨 0FALSIFIED
case3 抄底 ETHcase1 跨币种复现1419-1144.10%refuted -0.80%FALSIFIED
case4 抄底 BTC · makercase1 改限价成交 2bps/边1301-453.20%refuted -0.40%FALSIFIED
case2 是重点：三年 +34%，看着能发朋友圈。但同一窗口随机入场 200 笔，均值只差 +0.03%/笔且 95% 区间跨 0——统计上无法区分于抛硬币。2023-06 到 2026-10 是加密大牛市，随机入场也赚钱。钱是 beta 不是 alpha。
诚实的限制：引擎无法验证参数是否用全窗口调优过（它看得到曲线，看不到你的搜索过程）——所以参数网格与 walk-forward 只是必要不充分条件。样本不足时输出 INCONCLUSIVE，永不放过。
