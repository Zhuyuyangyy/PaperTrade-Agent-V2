02六件仪器

    
每次运行都会把这六件全开一遍。它们各自试图从不同角度杀死你的策略。

    

      

        
01Path-aware 回放

        
同一根 K 线里止盈和止损都被触及时，分别按「最坏优先」和「最好优先」各算一遍。真实结果是区间，不是那根最好看的线。

      

      

        
02成本敏感性 ×1/2/5

        
费率翻倍、翻五倍再跑。如果 edge 在 ×2 就消失，它本来就不够厚——这是最常见的死法。

      

      

        
03障碍可达性

        
止盈位在当前波动下多久能到？到不了的目标价，等于把收益写在了墙上。

      

      

        
04随机入场对照

        
同样笔数、同样持有期，随机方向跑 N 次（N 由 spec 里的 control.n_random 决定，内置演示是 200 次）。你的策略要赢的不是零，是这堆随机数的分布。

      

      

        
05Walk-forward

        
按时间切样本内 / 样本外分段复判。只在看得见的地方成立的 edge，不是 edge。

      

      

        
06参数网格

        
止盈 × 止损铺成 3×3，看有几格赚钱。只有个别参数组合成立 = 曲线拟合。

      

    

  


  
  

    
03这台仪器不做什么

    
把边界写清楚，比多列十个优点有用。


    

      它是离线回放引擎。不建模滑点、部分成交、容量冲击、相关性、交易所风险。
      每份报告第 8 节都会固定披露这一点——这不是免责声明，是这台仪器诚实的一部分。
    


    

      

        
约束说明

        
          
不预测收益只回答「这条曲线是不是幻觉」。不荐股、不带单、不代管资金、不承诺任何收益。

          
数据由你提供CSV 或内置演示数据。没有行情接口、没有网络请求、没有服务端。

          
裁决先于数字falsify_if 规则写在 spec 里，在跑出任何数字之前就存在，跑的过程中不能改。

          
浏览器内运行引擎通过 WebAssembly 在本机执行，你的 spec 与 K 线上传不到任何服务器。首次打开需联网取一次 Python 运行时（约 10MB，之后有浏览器缓存），此后每次运行都不再发请求。
