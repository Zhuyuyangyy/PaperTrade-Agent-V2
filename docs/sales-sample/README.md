## 这份答案里有什么是“看一眼数字”给不了的

1. **不是“亏了”，是“证据指向什么”**：三个变体的账面差异（-505% vs -575%）会让人以为
   “紧止盈更差，选宽的”。诊断层指出真正的问题是**入场打不过随机**——账面差异只是
   同一个病根的不同症状。调退出参数救不了入场的问题。
2. **下一步实验是可验收的**：“给入场加一个正交过滤器（趋势/时段/量能任选其一），信号数预计降到约 1/5——这是实验假设；验收标准：对照组差值 95% CI 下界 > 0（严格为正）且成交 ≥ min_fills”。原始建议见下：
   信号数预计降到约 1/5——这是实验假设，不是已验证结论”。买家拿到的不是评分，是下一步。
3. **规则先于数字**：证伪规则和诊断结论归类规则都写死在 spec 和引擎里，先于任何结果存在。
   买家可以自己重跑核对（spec 就在这个文件夹里）。
