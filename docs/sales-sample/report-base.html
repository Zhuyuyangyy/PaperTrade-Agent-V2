8. 诊断结论与下一步实验

主要结论：随机对照未通过　·　附带结论：过拟合迹象

证据（全部来自本次测量，无新增假设）：

  • 对照组：策略 − 随机 = -0.37%/笔，95% 区间 [-0.70%, -0.03%] 整体为负——入场逻辑显著差于随机（这是随机对照未通过的强形式：不是分不清，是更差）
  • 参数网格正格率 0% 低于 spec 声明的 50%（0/9 格为正）——edge 只在一小撮参数组合下存在

实验 1

  • 诊断：入场信号未展示出独立于随机入场的优势（统计上无法区分或显著更差）
  • 下一步实验：给入场加一个正交过滤器（趋势方向 / 时段 / 量能任选其一），信号数预计降到约 1/5——这是实验假设，不是目标
  • 验收标准：对照组差值 95% CI 下界 > 0（严格为正；下界为 0 时裁决引擎仍判未通过），且成交数仍 ≥ min_fills；若 CI 仍跨 0，换过滤器而不是降阈值

实验 2

  • 诊断：账面 -505.65% 且打不过随机：没有可测量的正期望
  • 下一步实验：停止调参。写下 edge 的市场学基础（谁在犯错、错误定价为什么持续）；写不出来就换假设，不要换参数
  • 验收标准：新假设的对照组差值 CI 下界 > 0（严格为正，不是 ≥ 0）

实验 3

  • 诊断：附带问题：样本外/网格显示参数脆弱
  • 下一步实验：主实验收敛后，用更少的参数重跑一次作为确认
  • 验收标准：砍参数后的结论与砍之前一致

以上为下一步实验假设，不是已证最优方案——按验收标准判定，不按感觉判定。

诊断结论与归类规则事前声明于 research/verify/diagnosis.py，先于任何策略被分类——与证伪规则同一条纪律。实验建议不是投资建议。

9. 未建模事项（阅读前必读）

  • 滑点与部分成交：只按费率+成交模型计成本，真实盘口的排队与部分成交不在模型内；
  • 样本外表现：walk-forward 未启用——所有数字都是窗口内的样本内结果；参数网格已启用，但它测量的是参数脆弱性而非时间维度上的稳健性，且网格本身也在窗口内测量，不能替代样本外验证。
  • 资金容量：等权回放，单笔金额对盘口的冲击（除费率外）未建模；
  • 同时持仓相关性：信号逐一独立回放，重叠持仓的相关性风险不计入；
  • 交易所/链路风险：宕机、API 限流、插针、宕机重启后的订单状态，一概不在模型内。
