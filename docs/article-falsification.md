# 我证伪了自己的交易系统，然后把"证伪"做成了产品

**副标题：4 个策略，4 个 FALSIFIED，包括那个三年赚了 +34% 的。**

---

## 一、先交代背景：我是那个把系统杀掉的人

过去几个月我做了一个六 agent 的纸面交易系统：搜索、风控、聪明钱、LLM 研判、FOMO、退出，六个 agent 轮流上岗，四本实验臂并行，WAL 账本、看门狗、止损跳空修复，工程上该有的一样不少。

36 小时后我拿到了结论，然后把系统停了。不是亏不起——是**测出来了期望值为负**：

- 六 agent 全开（E）vs 最笨的规则"无脑买 organic_score 前 3"（C）：-94.68 vs -102.75，**差 8 美元**。六个 agent 的增量约等于零。
- 14 个筛选队列的 lift，95% bootstrap 区间**全部跨 0**。没有一条过滤规则被证明有选择力。
- 每笔毛利 +18bps，而 AMM 的 LP 费地板是 50bps——**结构性为负**，和池深无关。

我没有删库跑路。我把"证明它不行"的那套仪器留下来了。然后我发现，这套仪器比系统本身值钱。

## 二、这个行业最贵的谎言：回测曲线

市场调研（完整版在我的仓库 `docs/market-scan-2026-10-29.md`）里几个硬数字：

- Broker Tested Reviews 用真钱实盘对照 6 个平台：**回测年化中位 35.2%，实盘 20.7%，差 14.3 个百分点**；Sharpe 从 1.82 掉到 0.94。
- 同一项测试：22 个零售 bot 里 **17 个只是纳指/S&P 的 beta**，营销话术叫"市场中性"。
- nof1.ai 的 Alpha Arena：GPT-5、Gemini 等六个前沿模型各领 $10,000 实盘 17 天，**四个亏 30%-63%**；唯一赢家 Qwen 靠 43 笔低频+严止损，手续费付了 $1,654。

问题是结构性的：**有 edge 的人不卖策略，卖策略的人没有 edge。** Reddit r/algotrading 的共识原话："如果你真造出了印钞机，你会卖掉它？"

于是市场上所有的"策略服务"都在卖同一件东西：**一条你无法验证的曲线**。而验证这件事，全行业都在糊弄。

## 三、六件仪器：把"验证"做成可复现的测量

我的引擎叫 `verify`（`research/verify/`），干的事只有一件：**输入一份策略 spec，输出一份试图杀死它的报告。** 六件仪器，全部来自这个项目用真金白银（纸面的）换来的教训：

**1. Path-aware 回放——你赚的是价差，还是假设？**

逐 bar 走价，同一根 K 线里止损和止盈同时触及时**默认判止损**，乐观读法并列打印。这不是学术洁癖：CascadeFader 仓库自己记录过，用"是否触及过止盈价"分析得到 +469%/91% 胜率，改成路径回放后是 +132%/PF 1.62。**同一批信号，差 3.5 倍。**

**2. 成本敏感性——edge 付不付得起自己的 toll？**

费率 ×1/×2/×5 重放。本项目实测：$100 单在池深中位 $799k 的池子里往返 60bps，其中 50bps 是 LP 地板，**和池深无关**。而配置里写的 120bps 其实是给 $1,000 单定的价——尺子用错了地方，不是数写错了。

**3. 障碍可达性——你的止损到底在工作吗？**

止盈/止损位是"价格在持仓窗口内会走到这里"的断言。直接量：案例1 的止损位 -8%，**只有 4.9% 的窗口被摸到**。回测里那个漂亮的止损，大部分时间根本没在工作，亏的时候全是超时钝刀割肉。

**4. 随机入场对照组——打不过抛硬币的策略，绝对收益没有意义。**

同窗口、同退出规则、同成本，入场 bar 随机抽。bootstrap CI 比均值。TrendRider 8468 笔 PF 0.84、CascadeFader PF 1.12，都过不了这关。

**5. Walk-forward——只在看得见的地方成立的 edge 不是 edge。**

窗口切 N 折，样本内（前 N-1 折）与样本外（最后 1 折）**各跑一遍完整电池**，同一批事前规则在样本外复判：样本外被证伪 → 整体 FALSIFIED；样本外样本不足 → INCONCLUSIVE，永不放过。行业第一死因是样本内过拟合（回测→实盘中位 -14.3pp），这台仪器就是冲它去的。

**6. 参数敏感性网格——edge 只在一小撮参数组合下存在，是曲线拟合不是 edge。**

退出参数（止盈/止损）在 spec 里**事前声明**一组候选值，引擎跑全网格：只有个别格子为正 → 打过拟合标记。demo 报告里 RSI 抄底 BTC 的 3×3 网格，样本内 0/9、样本外 0/9 全负——这个参数空间里没有 edge。信号参数不可网格化：改信号 = 改入场集 = 另一个实验。

**裁决不是分数，是事前证伪规则的判定。** `falsify_if` 写在 spec 里、先于任何数字存在：规则触发 → FALSIFIED；样本不足 → INCONCLUSIVE（不下结论）；否则 NOT_FALSIFIED，并附赠一句"未被证伪 ≠ 被证实"。事后改规则是营销，不是研究。

## 四、案例矩阵：四个策略，四种死法

统一设置：Binance 1h futures，29,347 根 K 线/币，2023-06 → 2026-10 真实缓存数据，taker 4bps，止盈 +3%/止损 -8%/超时 24h，随机对照 200 笔。

| 案例 | 成交 | 净收益 | vs 随机对照 | 裁决 |
|---|---:|---:|---|---|
| RSI 超卖抄底 BTC | 1310 | -505.65% | refuted（-0.37%） | FALSIFIED |
| **RSI 强势追涨 BTC** | 1638 | **+34.35%** | **unproven（+0.03%）** | **FALSIFIED** |
| RSI 超卖抄底 ETH | 1419 | -1144.10% | refuted（-0.80%） | FALSIFIED |
| RSI 抄底 BTC（maker 限价） | 1301 | -453.20% | refuted（-0.40%） | FALSIFIED |

**重点说第二个。** 三年 +34%，1638 笔，胜率过半，曲线能发朋友圈。但随机入场的对照组和它只差 +0.03%/笔，95% 区间跨 0——**统计上无法区分于抛硬币**。2023-06 到 2026-10 是加密大牛市，随机入场也赚钱。这条曲线卖的是 beta，包装成 alpha。

**这就是我想杀的东西。** 不是亏钱的策略——亏钱的策略自己会死；是**看起来赚钱、你也分不清是不是运气的策略**。它们收管理费、卖订阅、开星球，靠的就是你验证不了。

还有两个细节值得看：ETH 上同一个规则亏 1144%——**跨一个币种就不复现，是样本内巧合的指纹**；maker 限价把亏损从 -505% 收窄到 -453%——**费率减半改变量级，不改变符号**。

矩阵之外说一句诚实话：本项目历史上唯一赢得对照组的信号（资金费率极端值，每一种执行假设都赢随机）最终 PF 1.00 恰好打平——**有信息的信号也可能薄于摩擦**。引擎能输出"证明有选择性"，这一次的四个候选都不配。

## 五、过拟合检测：行业第一死因，得用专仪

前四件仪器回答"这条曲线是不是真的"，后两件回答更狠的问题：**它是只在你看得见的这段窗口里成立吗？**

回测→实盘中位差 -14.3pp，第一死因是样本内过拟合——参数在全窗口上挑过，曲线自然漂亮，未来根本不长这样。两台专仪：

**walk-forward**：demo 报告把 29,347 根 K 线切 3 折，样本内 -240.34% → 样本外 -265.31%（变化 -24.98pp）。这个案例里不是衰减，是**稳定地亏**；样本外段触发事前规则，按裁决规则整体 FALSIFIED——同一批规则在它没见过的数据上照样成立（这里是照样不成立）。

**参数网格**：事前声明 3×3 的止盈×止损组合，样本内 0/9、样本外 0/9 格净收益为正。如果 edge 只在某一格存在，那是刀刃上的曲线拟合；9 格全负，是这个参数空间里根本没有 edge。

诚实的限制也写在报告里：**引擎看不到你的参数搜索过程**——它不知道你是不是在全窗口上调优过。walk-forward 和网格是必要不充分条件，不是免罪金牌。样本不足时输出 INCONCLUSIVE，永不放过。

## 六、产品：只回答一个问题

```bash
python -m research.verify --demo --out report.md     # 看样例
python -m research.verify --spec your.json --candles klines.csv --signals sig.csv --out report.md
```

输入一份 JSON spec（假设、退出规则、成本假设、**事前证伪规则**），输出一份 markdown 报告：path-aware 回放（最坏/最好并列）、成本敏感性、障碍可达性、随机对照组、证伪规则逐条判定、以及固定的"未建模事项"一节——**不知道仪器边界的人会滥用仪器**。

现在的形态：

- **引擎**：开源（MIT），361 个测试（`test_verify.py` 60 个）全绿，离线可跑，`docs/verify-sample-report.md` 是真实数据样例
- **服务**：你带策略来（信号 CSV 或规则描述），我出证伪报告。**首 10 单免费**，换公开发布的 case study 授权
- **不碰的**：不荐股、不带单、不代管资金、不承诺收益。我只回答一个问题：**你的曲线是不是幻觉。**

## 七、这个方法论的通用部分

最后说点超出交易的。这套东西的本质是**"内部逻辑一致性优先于外部叙事"**：

- 规则先于数字（事前证伪），因为事后挑规则是自欺；
- 对照组先于结论，因为分不清 beta 和 alpha 的人不配谈 edge；
- 披露先于推销，因为藏着假设的数字是营销。

我杀过自己的系统，现在帮别人杀他们的。**杀不死的，才值得上真钱。**
