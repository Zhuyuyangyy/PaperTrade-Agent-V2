# 我杀掉了自己做了三个月的六 agent 交易系统，然后把"杀人"做成了产品

先交代结局：系统是我自己停的，停之前它没爆仓、没归零、曲线甚至能看。

过去几个月我做了一个六 agent 的纸面交易系统——搜索、风控、聪明钱、LLM 研判、FOMO、退出，六个 agent 轮流上岗，四本实验臂并行，WAL 账本、看门狗、止损跳空修复，工程上该有的一样不少。我在它上面花的功夫，足够我在大多数技术面试里吹四十分钟。

36 小时后，我拿到了结论，然后把它停了。

不是亏不起。是**测出来了期望值为负**，而且测得很干净：

- 六个 agent 全开（实验臂 E）vs 最笨的规则"无脑买 organic_score 前 3"（对照组 C）：**-94.68 vs -102.75，差 8 美元**。六个 agent、三个月的工程，增量约等于零。
- 14 个筛选队列的 lift，95% bootstrap 区间**全部跨 0**。没有一条过滤规则被证明有选择力。
- 每笔毛利 +18bps，而 AMM 的 LP 费地板是 50bps——**结构性为负**，和池子多深无关。

说不好奇是假的。我也想过"再调调参数""换个信号试试"。但数据就摆在那儿：我不是在运营一个系统，我是在给一个负期望值的东西续费。

## 然后我发现，比系统值钱的是那套"杀死它"的仪器

我没有删库跑路。恰恰相反，我把"证明它不行"的那套工具留了下来，打磨成了一个开源的策略证伪引擎 `verify`（MIT，361 个测试全绿，离线可跑）。

为什么？因为我发现这个行业里最贵的谎言不是"我赚了多少钱"，而是**一条你无法验证的曲线**。

看几个市场调研里的硬数字（完整版在仓库 `docs/market-scan-2026-10-29.md`）：

- Broker Tested Reviews 用真钱实盘对照 6 个平台：**回测年化中位 35.2%，实盘 20.7%，差 14.3 个百分点**；Sharpe 从 1.82 掉到 0.94。
- 同一项测试：22 个零售 bot 里 **17 个只是纳指/S&P 的 beta**，营销话术叫"市场中性"。
- nof1.ai 的 Alpha Arena：GPT-5、Gemini 等六个前沿模型各领 $10,000 实盘 17 天，**四个亏 30%-63%**；唯一赢家 Qwen 靠 43 笔低频+严止损，手续费付了 $1,654。

问题是结构性的：**有 edge 的人不卖策略，卖策略的人没有 edge。** Reddit r/algotrading 的共识原话："如果你真造出了印钞机，你会卖掉它？"

于是市场上所有的"策略服务"都在卖同一件东西：一条你验证不了的曲线。而验证这件事，全行业都在糊弄。

所以我把仪器留下了。输入一份策略 spec，输出一份**试图杀死它**的报告。六件仪器，全部来自这个项目用真金白银（纸面的）换来的教训：

**1. Path-aware 回放——你赚的是价差，还是假设？**

逐 bar 走价。同一根 K 线里止损和止盈同时触及时，默认判止损，乐观读法并列打印。这不是学术洁癖：CascadeFader 仓库自己记录过，用"是否触及过止盈价"分析得到 +469%/91% 胜率，改成路径回放后是 +132%/PF 1.62。**同一批信号，差 3.5 倍。**

**2. 成本敏感性——edge 付不付得起自己的 toll？**

费率 ×1/×2/×5 重放。尺子用错地方比数写错了更常见：本项目实测 $100 单在池深中位 $799k 的池子里往返 60bps，其中 50bps 是 LP 地板，和池深无关；而配置里写的 120bps 其实是给 $1,000 单定的价。

**3. 障碍可达性——你的止损到底在工作吗？**

止盈/止损位是"价格在持仓窗口内会走到这里"的断言，那就直接量。案例 1 的止损位 -8%，**只有 4.9% 的窗口被摸到**。回测里那个漂亮的止损，大部分时间根本没在工作，亏的时候全是超时钝刀割肉。

**4. 随机入场对照组——打不过抛硬币的策略，绝对收益没有意义。**

同窗口、同退出规则、同成本，只有入场 bar 随机抽。TrendRider 8468 笔 PF 0.84、CascadeFader PF 1.12，都过不了这关。

**5. Walk-forward——只在看得见的地方成立的 edge 不是 edge。**

窗口切 N 折，样本内与样本外各跑一遍完整电池，同一批事前规则在样本外复判。

**6. 参数敏感性网格——edge 只在一小撮参数组合下存在，是曲线拟合不是 edge。**

退出参数在 spec 里**事前声明**一组候选值，引擎跑全网格，看分布而不是看最好的那一格。

## 四个策略，四种死法（包括那个赚钱的）

统一设置：Binance 1h futures，29,347 根 K 线/币，2023-06 → 2026-10 真实缓存数据，taker 4bps，止盈 +3%/止损 -8%/超时 24h，随机对照 200 笔。四个 spec 的假设、证伪规则、成本假设全部先于结果写死，跑完不分好坏全部发布。

| 案例 | 成交 | 净收益 | vs 随机对照 | 裁决 |
|---|---:|---:|---|---|
| RSI 超卖抄底 BTC | 1310 | -505.65% | refuted（-0.37%，CI[-0.70,-0.03]） | FALSIFIED |
| **RSI 强势追涨 BTC** | 1638 | **+34.35%** | **unproven（+0.03%，CI 跨 0）** | **FALSIFIED** |
| RSI 超卖抄底 ETH | 1419 | -1144.10% | refuted（-0.80%） | FALSIFIED |
| RSI 抄底 BTC（maker 限价） | 1301 | -453.20% | refuted（-0.40%） | FALSIFIED |

**重点说第二个。** 三年 +34%，1638 笔，胜率过半，曲线能发朋友圈。但随机入场的对照组和它只差 +0.03%/笔，95% 区间跨 0——**统计上无法区分于抛硬币**。2023-06 到 2026-10 是加密大牛市，随机入场也赚钱。这条曲线卖的是 beta，包装成 alpha。

它一样被判了 FALSIFIED。因为裁决不是分数，是**事前证伪规则**的判定：`falsify_if` 写在 spec 里、先于任何数字存在。规则触发 → FALSIFIED；样本不足 → INCONCLUSIVE（不下结论）；否则 NOT_FALSIFIED，并附赠一句"未被证伪 ≠ 被证实"。

**这就是我想杀的东西。** 不是亏钱的策略——亏钱的策略自己会死；是**看起来赚钱、你也分不清是不是运气的策略**。它们收管理费、卖订阅、开星球，靠的就是你验证不了。

## 诚实的部分

这个引擎也有射程之外的东西，我写在每份报告的"未建模事项"里：引擎看不到你的参数搜索过程，它不知道你是不是在全窗口上调优过。walk-forward 和网格是必要不充分条件，不是免罪金牌。

矩阵之外说一句更诚实的：本项目历史上唯一赢得对照组的信号（资金费率极端值，每一种执行假设都赢随机）最终 PF 1.00 恰好打平——**有信息的信号也可能薄于摩擦**。引擎能输出"证明有选择性"，只是这四个候选都不配。
