# 视频口播稿：三年赚 34% 的策略，我为什么说它是幻觉

**平台**：B 站 / 视频号 ｜ **时长**：约 75 秒 ｜ **基调**：诚实、自嘲、语速偏快但不赶

---

## 时间轴与口播

### 【0-8s】钩子（正面机位，无背景音乐或极简）

三个月前，我停掉了自己做的六 agent 交易系统。

工程花了不少，WAL 账本、看门狗、止损跳空修复，该有的一样不少。36 小时后我拿到结论，把它停了——六个 agent 全开，对比最笨的规则，**差 8 美元**。增量约等于零。

### 【8-25s】行业背景（屏幕录制市场调研数字页）

但真正扎心的不是这个。是停完之后我去调研，发现整个行业都在卖同一种东西：**一条你无法验证的曲线**。

回测年化中位 35.2%，实盘 20.7%，差 14.3 个百分点。22 个零售 bot，17 个只是指数 beta，包装成"市场中性"。六个前沿大模型各领一万美元实盘，四个亏了三到六成。

有 edge 的人不卖策略，卖策略的人没有 edge。

### 【25-55s】核心案例（分屏：左曲线图，右案例报告）

于是我把"证明它不行"的仪器留下，做成了一台证伪引擎。然后拿四个策略开刀，四个全灭。

重点说第二个。RSI 追涨 BTC，三年 **+34%**，1638 笔，胜率过半，这条曲线能发朋友圈。

但我让它在同一窗口、同一退出规则下，跟 200 笔随机入场对照——**只差 0.03%**，置信区间跨 0。统计上，**无法区分于抛硬币**。

那三年是大牛市。随机入场也赚钱。它卖的是 beta，包装成 alpha。

所以它赚钱，我照样判它 FALSIFIED。

### 【55-72s】方法论一句带过 + 态度（回到正面机位）

三个问题，你拿去问任何策略：同一根 K 线止损止盈同时触及，你的回测悄悄选了哪个？费率翻倍，edge 还付不付得起 toll？只在你看得见的窗口里成立，算不算成立？

规则先于数字。事后改规则，是营销，不是研究。

### 【72-75s】收尾金句（定格，出字幕）

我杀过自己的系统。杀不死的，才值得上真钱。
